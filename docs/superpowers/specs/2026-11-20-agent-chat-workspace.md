# Orbit Agent chat workspace

The V2 Agent workspace follows the reference composition. Orbit's main navigation and top bar frame a collapsible chat sidebar on the left and a broad conversation area on the right. The sidebar has Recent and Projects views, search, and a prominent new-chat action. Projects are Orbit task projects. Each can expand to list its conversations and selecting its label starts a blank chat in that project. The project name appears above the conversation. The Projects view offers project creation using the existing Orbit form and an All projects action that shows the complete list and returns a selected project to a blank unscoped composer. Sidebar controls use the topbar glass-pill styling.

Chat starts with a centered composer, an actionable heading, and three Orbit starter prompts underneath. The first message opens the active conversation layout and moves the composer to the bottom at the full width of the conversation. Assistant replies use open text with readable line lengths and larger typography. User messages are aligned to the right. File, image and mode controls are visible in the composer. During a cancellable response, Stop occupies the Send slot until the run finishes. Orbit tokens govern both themes. Narrow screens use a collapsible sidebar overlay with Escape, focus return, and room to write and send.

Opening Agent from primary navigation starts a blank chat in both V1 and V2. Direct conversation links and an explicit handoff from the floating assistant keep the requested conversation and its draft. The V1 workspace keeps its current layout. Back and Forward, selecting a chat or project, and starting another chat honor draft-discard confirmation within the workspace. Opening a blank chat makes no conversation-create request. A conversation is created on the first send.

The existing conversation project context is the source of project membership. Conversation summaries expose the nullable project ID. Conversation creation may accept a validated project ID, checks ownership before storing it, and uses the existing request ID to retry the same creation. Older conversations without an available project still appear in Recent. An invalid project route shows a recovery action and cannot send a message with an unavailable project. Loading, fetch errors, and empty search results have distinct states. Agent mode, attachments, streaming, and existing task and skill actions keep their current contracts.
