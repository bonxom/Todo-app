## Browser method and limits

Used Chromium through Playwright against a Vite server launched from this worktree on port **5127**, isolated from port 5000, which was being used by another checkout. The reproduction config is `/tmp/statistics-review.playwright.config.ts` (temporary, not committed). It inherits the repository config, sets the absolute test/output directories and baseURL, and launches `pnpm exec vite --host 127.0.0.1 --port 5127 --strictPort` with `reuseExistingServer: false`.

Clicked presets, edited date inputs, selected heatmap days, opened/closed details, retried failed requests, switched V1/V2, navigated to tasks, switched languages/themes, and opened the assistant side dock. Tested keyboard Enter and focus restoration, zero data, single-day selection, reduced motion and long metadata. Viewports: 360, 390, 768 and 1440px. Screen captures were opened and visually inspected, including mobile task details, light/dark desktop and Vietnamese dock layout.

API responses were deterministic browser fixtures. This validates the real frontend and HTTP/query integration under controlled responses, **not** a live MongoDB-backed account or live AI conversation. The assistant fixture does not supply a successful conversation session; dock layout was tested, AI conversation behavior was not. Chromium was the only browser engine used. The day-switch browser test verifies selection/result isolation for sequential changes; it does not claim reversed-network-response race coverage.
