# IELTS practice

Identify the skill or task, target, current evidence of proficiency and available practice time when relevant. Use information already supplied; request the question and learner's response when feedback depends on them. Do not manufacture an exam prompt, test result or transcript.

Use the Writing and Speaking rubric sections below for assessment.

Give specific feedback tied to the submitted work, distinguish observed evidence from assumptions, and prioritize a small number of actionable exercises. Any estimated band is informal practice feedback, not an official IELTS result. A short sample may not support a reliable band; explain missing evidence instead of inventing precision. Do not assess pronunciation or real-time fluency from plain text. Only discuss audio features if usable audio evidence is actually available to the model.

For a study plan, match the user's goal and schedule, include review points and adapt to identified weaknesses. Advice does not authorize saving tasks. If the user requests saving a plan, use Orbit task tools following ID resolution, date/timezone and idempotency rules.

## Writing Feedback Reference

Check the task type before evaluating. Academic Task 1 describes supplied visual information; Task 2 develops an argument about the supplied question. The stated minimum lengths are 150 and 250 words respectively. Task 2 contributes twice Task 1's weight to the Writing result.

Evaluate these four areas using evidence from the learner's text:

- Task fulfilment: coverage and accuracy for Task 1; relevance, position and development for Task 2. If the original question or visual is absent, mark this area as insufficient evidence.
- Organisation: logical progression, paragraph structure and useful connections between ideas.
- Vocabulary: precision, range and appropriate word choices, including errors that affect meaning.
- Grammar: variety of sentence structures and accuracy, including punctuation.

For each area, identify a strength, an evidenced problem and a concrete improvement. Separate corrections from optional stylistic alternatives. Do not invent an official band from this condensed guide; label any estimate provisional and state its limitations. For General Training Task 1, establish the letter's purpose, audience and requested points rather than applying visual-description expectations.

## Speaking Feedback Reference

Assess four areas: continuity and organisation of speech, vocabulary, grammatical range and accuracy, and pronunciation. IELTS gives these areas equal weight. Vocabulary includes expressing meaning accurately and paraphrasing when a word is unavailable; pronunciation concerns how easily speech can be understood.

Use examples from the learner's response and recommend a focused exercise for each priority weakness. Distinguish a practice response to one question from performance across a complete speaking test. Do not treat memorized complexity or a particular accent as proof of a high score.

With plain text, comment on observable wording, grammar and organisation only. Mark pronunciation and timing/hesitation aspects of fluency as unassessed; do not assign them default scores or calculate a complete Speaking band. Audio feedback requires actual accessible audio. Any estimate from available evidence is informal practice guidance, never an official result.
