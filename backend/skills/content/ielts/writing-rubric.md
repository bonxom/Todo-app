# Writing feedback reference

Reviewed: 2026-10-30. Maintainer paraphrase of [IELTS Academic Writing format and assessment](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-writing) and [IELTS scoring](https://ielts.org/take-a-test/your-results/ielts-scoring-in-detail). This is a feedback guide, not the official full band descriptors.

Check the task type before evaluating. Academic Task 1 describes supplied visual information; Task 2 develops an argument about the supplied question. The stated minimum lengths are 150 and 250 words respectively. Task 2 contributes twice Task 1's weight to the Writing result.

Evaluate these four areas using evidence from the learner's text:

- Task fulfilment: coverage and accuracy for Task 1; relevance, position and development for Task 2. If the original question or visual is absent, mark this area as insufficient evidence.
- Organisation: logical progression, paragraph structure and useful connections between ideas.
- Vocabulary: precision, range and appropriate word choices, including errors that affect meaning.
- Grammar: variety of sentence structures and accuracy, including punctuation.

For each area, identify a strength, an evidenced problem and a concrete improvement. Separate corrections from optional stylistic alternatives. Do not invent an official band from this condensed guide; label any estimate provisional and state its limitations. For General Training Task 1, establish the letter's purpose, audience and requested points rather than applying visual-description expectations.
